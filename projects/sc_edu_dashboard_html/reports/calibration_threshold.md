## 0. 背景与结论摘要

主分析（model_card.md）暴露两个可用性问题：**概率高估**（class_weight=balanced）、**统一阈值 0.5 对低风险组漏判**。
本扩展给出可执行修正与敏感性证据：

1. **概率校准**：在训练集 5 折 OOF 概率上拟合校准器（Platt / Isotonic），测试集只做评估。
   选优 **isotonic**，ECE 从 0.192 降至 0.052，
   Brier 0.221 → 0.185，
   平均预测概率 0.477 → 0.298（更接近实际风险率）。
2. **决策阈值**：校准后测试集扫描 0.05~0.90，推荐阈值 **0.20**
   （在召回率 >= 0.80 的前提下精确率最高（precision=0.359，recall=0.912）），此时标记 145 人（72.5%），
   precision=0.359、recall=0.912。
3. **分组阈值（只降不升 / 向上对齐）**：目标 recall=0.653（整体统一阈值下的 OOF recall）。
   达标组 6 -> 15，
   组间 recall 最大差距 0.564 -> 0.256；
   标记人数 1632 -> 1964，
   平均精确率 0.451 -> 0.425
   （以误报增加换漏判减少，需业务成本权衡）。
4. **风险标签阈值**：t 从 50 到 65，风险率 10.3% → 39.9%；
   CV macro-F1 在 t=60 处最高（0.656），说明当前标签定义下模型区分度最好。

## 1. 概率校准（训练集 OOF 拟合，不泄漏测试集）

协议：训练集内 5 折 OOF 概率拟合校准器 -> 测试集应用并评估（测试集不参与拟合）。

| 方法 | ECE（越小越好） | Brier | 平均预测概率 | 最大分箱偏差 |
| --- | ---: | ---: | ---: | ---: |
| none | 0.1922 | 0.2209 | 0.4772 | 0.3103 |
| platt | 0.0669 | 0.1796 | 0.2984 | 0.1249 |

- **选优方法：isotonic**（测试集 ECE 最小）。校准前后对比：
  ECE 0.192 → 0.052；
  Brier 0.221 → 0.185。
- 解读：校准解决「概率不能当风险分」的问题；Isotonic 更灵活但可能在小测试集上过拟合（此处 ECE 最小）。
  校准器只由训练集 OOF 概率拟合，测试集概率仅用于应用与评估，**不存在测试集泄漏**。

## 3. 分组阈值调整（只降不升 / 向上对齐）

**口径**：使用与 fairness_report.md 完全一致的「全量 OOF 原始未校准概率 + 统一阈值 0.5」
（不用校准后概率，避免 Isotonic 阶梯离散化导致阈值无法精细控制；也让本节可与既有公平性结论直接对比）。
**目标 recall = 整体统一阈值下的 OOF recall = 0.653**。
样本 < 20 的组跳过：无（全量 1,000 人，所有子组 n>=20）。

**调整规则（2026-10-29 质控修正）**：只降不升 ——
① 统一阈值下组内 recall 已 >= 目标的组**保持 0.5 不变**（禁止提高阈值让 recall 下降，那是「向下拉平」，与公平性目标相反）；
② 未达标组在 [0.05, 0.5] 内降低阈值，取「recall 达标前提下阈值最高」（最保守、误报最少）的方案；
③ 区间内无解的组取 recall 最大处并标注「未达标」。
