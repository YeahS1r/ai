# 学生成绩分析数据看板（HTML 版）

双击 index.html 即可在浏览器打开，无需安装 Python、无需联网。

包含 6 个页面（顶部或侧边导航切换）：
1. 总览
2. 数据质量
3. 分组差异与影响因素
4. 模型与公平性
5. 学生画像与洞察
6. 报告与图表中心（9 份报告下载 / 33 张图浏览 / 数据与模型产物下载）

说明：
- 本目录下 figures/、reports/、data/ 为相对路径资源，请保持目录结构完整（不要只复制 index.html）。
- 全局筛选器只影响总览与数据质量页（其他页为全量口径，页面内已标注）。
- 数据为 student-scores.csv（1,000 名学生），风险定义 avg_score < 60；结论均为关联，不做因果推断。
